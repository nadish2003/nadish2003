## Selected projects

### Movie Ticket Booking System

A full-stack application for browsing movies, choosing showtimes and seats, and managing bookings. Includes customer and administrator interfaces, JWT authentication, booking conflict checks, and simulated payment workflows.

**My role:** Developed the complete project, including the frontend and backend.  
**Stack:** React · TypeScript · Tailwind CSS · Spring Boot · Spring Security · MySQL

[Frontend](https://github.com/movie-booking-nadish/movie-booking-frontend) · [Backend](https://github.com/movie-booking-nadish/movie-booking-backend)

### CATMS — Clinic Appointment & Treatment Management System

A team project for managing clinic appointments, consultations, prescriptions, and billing across multiple branches.

**My contribution — Clinical Consultations & Treatment Prescriptions:** Treatment catalogue search and category filters, policy coverage lookups, consultation records with vitals and diagnoses, multi-item prescriptions, and the database procedure for completing consultations and generating invoices.

**Project stack:** React · Python · FastAPI · MySQL

[Frontend](https://github.com/CATMS-System/CATMS-frontend) · [Backend](https://github.com/CATMS-System/CATMS-backend) · [Demo deployment](https://catms-frontend.onrender.com)

### SAMS — Student Attendance Management System

A desktop application for managing students, lecturers, class schedules, and attendance. Includes administrator and lecturer roles, scheduling conflict detection, and attendance reports with filters and summary percentages.

**My role:** Developed the complete application.  
**Stack:** Java · JavaFX · MySQL · JDBC · Maven

[View repository](https://github.com/nadish2003/SAMS)
